A responsive, feature-packed client-side web application built for instant recipe search, diet and cuisine filtering, step-by-step cooking modal views, and persistent favorite management. Built as part of the Grow Grid Full Stack Web Development capstone curriculum.

## Features

- **Dynamic Search:** Search for dishes by name or ingredients in real time.
- **Advanced Filtering:** Filter search results by cuisine types (Italian, Mexican, Asian, Indian) and dietary rules (Vegetarian, Vegan, Gluten-Free).
- **Detailed Recipe Modals:** Click on any recipe card to view required ingredients and complete cooking instructions.
- **Save Favorites:** Store favorite recipes locally using the browser `localStorage` API.
- **Dark Mode Support:** Smooth light/dark visual theme switching using CSS custom properties.
- **Responsive Layout:** Optimized grid UI for mobile, tablet, and desktop screens.
